# Security

Maildock provides access to configured mailboxes and can send mail on their behalf. Treat a deployment as a high-value account.

Read [docs/SECURITY.md](docs/SECURITY.md) for the current security architecture and [docs/BACKUP_AND_RECOVERY.md](docs/BACKUP_AND_RECOVERY.md) for restore security.

## Reporting a vulnerability

Do not publish credentials, mail content, tokens, recovery codes, private deployment details or sensitive reproduction data in a public issue.

If private vulnerability reporting is enabled for this repository, use it. Otherwise open a minimal issue asking for a private contact method without including sensitive technical details.

Maildock has not been independently certified or externally audited. See [Limitations and operator responsibilities](docs/SECURITY.md#limitations-and-operator-responsibilities) for what the project does and does not claim.
